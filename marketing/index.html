01 // INFERENCE

Universal
Proxy

  • One integration across providers and models
  • Normalized request/response + streaming (SSE)
  • Tool call schema capture (inputs, outputs, errors)
  • Tokens, latency, and cost accounting per run
  • Trace/span context propagation across services
  • Fail-open / fallback routing with explicit policies
  • Optional caching with explicit bypass controls
02 // SURVEILLANCE

Agent-Native
Observability

  • Session-first debugging: start from the run, not the log line
  • Timeline view + raw trace view (all context preserved)
  • Run graph: branches, retries, tool calls, and outcomes
  • Permalinks to exact failing sessions for reviews
  • Tool call introspection: args, responses, latency, exceptions
  • Audit-friendly: stable IDs for runs, steps, and artifacts
03 // ANALYSIS

Semantic
Evaluation

  • LLM judge with full audit trail (model + prompt + rubric versioned)
  • Criteria checklist scorer (pass/fail + graded)
  • Tool correctness scoring (schema + output validation)
  • Outcome/decision scoring for agent trajectories
  • Deterministic checks (exact/regex) for guardrails
  • Compare experiments across prompt/model versions with diffs
